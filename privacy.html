Privacy Policy

Effective date: October 14, 2026

Channel Roster ("the app") is a personal research tool that runs only on its owner's own computer. It has no hosted server, no user accounts and no other users. This policy explains what data the app accesses, how it is used and stored, and how access can be removed.

1. Data the app accesses

Google Ads API

When the owner signs in with Google and grants permission, the app requests the Google Ads scope (https://www.googleapis.com/auth/adwords). It uses that access only to call the Google Ads Keyword Planner service on the owner's own Google Ads account, to read:

  • average monthly search-volume estimates for keywords,
  • monthly search-volume history for the past year,
  • advertiser competition levels, and
  • related keyword ideas.

The app does not read, create, change or delete campaigns, ads, budgets, billing or payment information, and it does not access any other Google Ads account.

Google sign-in tokens

Granting permission produces an OAuth refresh token. The app stores it in a local configuration file on the owner's computer, and keeps short-lived access tokens in memory only.

YouTube Data API and public YouTube information

The app reads publicly available information about YouTube videos and channels, such as titles, descriptions, tags, view counts, subscriber counts and publish dates, using an API key. It also reads YouTube's public search suggestions. No YouTube account is signed in, and no private YouTube data is accessed.

Other services

For optional topic-grouping features, the app may send titles of public videos to the Google Gemini API for analysis. It does not send any Google Ads data or personal information to Gemini.

2. How the data is used

The data is used only to show the owner keyword research, competition analysis and trend information inside the app, to help plan video topics. It is not used for advertising, profiling, selling, or training artificial intelligence or machine learning models.

3. Storage and retention

  • All data is stored in a SQLite database file and a configuration file on the owner's computer. There is no cloud database and no copy elsewhere.
  • Keyword Planner responses are cached for up to 7 days to avoid repeat requests. Keyword results the owner chooses to keep, such as saved keywords and research history, remain until the owner deletes them.
  • Deleting the database file removes all stored research data. Deleting the refresh token from the configuration file removes the stored authorization.

4. Sharing

The app does not sell, rent, transfer or disclose data received from Google APIs to anyone. Data is only sent back to the Google services listed above, as part of making the requests described in this policy.

5. Limited Use of Google user data

Channel Roster's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Security

Credentials and data never leave the owner's computer except in encrypted (HTTPS) requests to Google's APIs. The app only listens on the computer itself (127.0.0.1) by default and does not show credentials in its interface.

7. Removing access

Google account access can be revoked at any time at myaccount.google.com/permissions. After revoking, the app can no longer read Google Ads data.

8. Children

The app is a personal tool and is not directed at children under 13. It does not knowingly collect information from children.

9. Changes to this policy

If the app's data practices change, this page will be updated and the effective date above revised.
