Channel Roster

A personal research tool for planning video content. It runs only on its owner's own computer and is not a public service or a product for sale.

Channel lists

Keep named lists of channels and see their public subscriber and view counts.

Outlier videos

Find recent public videos that performed unusually well for their channel.

Keyword research

Compare search demand, competition and trends for video topic ideas.

How it uses Google data

Channel Roster connects to these Google services using its owner's own credentials:

  • Google Ads API (Keyword Planner): with the owner's permission, it reads keyword search-volume estimates, monthly history and related keyword ideas from the owner's own Google Ads account. It does not create, change or delete campaigns, ads or billing settings.
  • YouTube Data API: it reads public video and channel information (titles, view counts, subscriber counts) using an API key. No sign-in is used for this.

All data stays in a database file on the owner's computer. Nothing is sold, shared or used for advertising. Read the full Privacy Policy.

Channel Roster is an independent personal project. It is not affiliated with, endorsed by or sponsored by Google LLC or YouTube.
